# Ship a macOS application bundle with ad-hoc signing and macOS CI coverage

The macOS desktop release ships as `WinMTR.app`, one bundle for `osx-arm64`
and one for `osx-x64`. Finder and the Dock need an application bundle for
normal launch, product identity, and an icon. A bare executable archive does
not provide that shell experience.

This decision supersedes only the final bundle follow-up note in
[ADR 0007](0007-native-aot-release-matrix.md): the bundle is now release work,
not deferred work, and the normal launch path is `WinMTR.app`. ADR 0007 is
left unmodified. Its Native AOT choice and single-Mac release build strategy
remain in force.

## Bundle and signing policy

- `Contents/MacOS` contains the full desktop publish payload, including native
  libraries and excluding symbols. Staging only the apphost is a pre-existing
  defect; the payload repair applies to every desktop runtime identifier.
- `Contents/Resources` contains the Route Pulse ICNS icon, generated by the
  existing artwork generator. The bundle also contains `Info.plist` and
  `PkgInfo` (`APPL????`). The icon is committed as a binary asset, not edited
  by hand.
- Metadata identifies executable `winmtr`, name and display name `WinMTR`,
  identifier `com.kzagoris.winmtr`, icon `winmtr-route-pulse.icns`, package
  type `APPL`, dictionary version `6.0`, principal class `NSApplication`,
  high-resolution support, and the utilities category. The minimum macOS
  version follows the supported OS matrix of the pinned .NET SDK.
- Both Apple version fields use the validated numeric release part. The full
  development version belongs only in a private metadata key and the
  application's version display.
- Sign nested Mach-O files first, then sign the bundle ad-hoc. Native AOT
  needs no JIT entitlements; this policy uses no entitlements. Ad-hoc signing
  supplies local signature integrity without paid signing credentials. It
  does not establish Developer ID trust or provide notarization, and does
  not remove Gatekeeper or quarantine warnings.
- Document right-click and Open and the bundle-targeted quarantine command
  in the README. The release stays a prerelease until a hand smoke passes
  on both Apple Silicon and Intel hardware. Evidence must name the
  architecture actually launched; cross-compiling is not execution evidence.

Developer ID signing, notarization, Mac App Store submission, DMG or PKG
installers, and Parcel are out of scope. A universal binary remains rejected;
each user downloads only their architecture. The console keeps its plain
archive and does not gain a bundle.

## CI runner cost

Add one macOS runner to the regular CI matrix before macOS-only shell code
lands. The release matrix already has a Mac for Native AOT publishing; that
does not exercise macOS-only changes during normal CI. The additional runner
builds and runs the fast suite on macOS before tag time.

ADR 0007 rejected a second Mac release job because, for the private repository
at the time of that decision, macOS minutes billed at ten times the rate and
would double the most expensive release-matrix line. That cost reasoning
still argues against a redundant Intel release builder, particularly given
the Intel runner's retirement. Here the extra cost buys a different guard:
platform execution on regular CI changes, not a second cross-compilation.
Accept the additional macOS CI job cost on each eligible workflow run. No
fixed monetary estimate is claimed; the charge depends on job duration,
repository billing status, and runner pricing. Do not add a second Mac
release job or treat CI as a substitute for the two-architecture hand smoke.

Release bundle assertions check metadata, numeric version semantics, ad-hoc
signature validity, expected native libraries, executable mode, and icon
decoding. These catch packaging defects before upload but do not clear the
Native AOT run-time risk recorded in ADR 0007.

The shell's menus, lifetime, visual scope, and pending design approval are
recorded in the [macOS shell design section](../specs/avalonia-front-end/design.md#9-macos-shell).
